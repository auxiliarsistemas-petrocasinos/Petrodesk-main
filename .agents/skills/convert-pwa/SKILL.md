# Convert to PWA
1. Inspect framework, deployment, asset paths, auth, data sensitivity, and existing workers.
2. Define installability, offline scope, freshness, updates, and cache budget before tooling.
3. Create a valid manifest with stable identity, colors, display, scope, start URL, and icons.
4. Never cache secrets, personalized APIs, mutations, or auth callbacks without reviewed design.
5. Provide honest offline/error UI, timeouts, retry, activation, and update notification.
6. Preserve App Router/RSC semantics and avoid stale authenticated HTML.
7. Verify installability, offline navigation, update flow, HTTPS, responsiveness, and Lighthouse.
