# Create a form
1. Model fields, authorization, persistence, validation, and failure modes before UI work.
2. Share a runtime schema where useful; never trust client validation alone.
3. Provide labels, descriptions, field errors, error summary, keyboard flow, focus, and autocomplete.
4. Keep privileged mutations server-side; prevent CSRF where relevant, replay, duplicates, and over-posting.
5. Handle pending, retry, success, dirty, reset, and unsaved-change behavior intentionally.
6. Test validation, authorization, failure, keyboard use, and success; run all quality gates.
