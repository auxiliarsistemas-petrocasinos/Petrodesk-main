# Optimize for mobile
1. Audit narrow viewports, orientation, zoom, keyboard, safe areas, reduced motion, slow network, and offline transitions.
2. Prioritize tasks, hierarchy, reachable navigation, large touch targets, readable type, focus, and errors.
3. Remove overflow, layout shift, hover-only UI, fixed-height traps, and keyboard-obscured controls.
4. Measure and improve images, fonts, interaction latency, initial JavaScript, and loading.
5. Preserve semantics and essential content across breakpoints.
6. Verify through browser automation/Lighthouse plus keyboard and screen-reader-oriented checks.
