# Create a page
1. Inspect routing, layouts, design tokens, data access, authorization, and neighboring pages.
2. Explain requirements, plan, risks, alternatives, and Server/Client Component boundaries.
3. Define metadata plus loading, error, not-found, empty, and permission states.
4. Implement mobile-first semantic UI; keep data on the server and isolate interactivity.
5. Optimize images, fonts, imports, caching, and PWA navigation; add focused tests.
6. Run lint, typecheck, tests, build, browser/Lighthouse checks, and document decisions.
Never assume Next.js when the repository currently uses another router; propose migration boundaries first.
