# Optimize performance
1. Establish a reproducible baseline, user impact, environment, and target budget.
2. Separate network, server, database, render, hydration, asset, and bundle costs.
3. Rank evidence-backed hypotheses and tradeoffs before editing.
4. Apply the smallest high-leverage change in queries, caching, concurrency, boundaries, assets, or imports.
5. Avoid cargo-cult memoization, caching without invalidation, and unmeasured indexes.
6. Repeat the same measurement; report before/after, regression risk, and remaining bottleneck.
