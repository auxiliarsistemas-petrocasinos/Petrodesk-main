# Create a dashboard
1. Define audience, decisions, metric formulas, freshness, permissions, and source queries.
2. Plan hierarchy before charts; prioritize actionable KPIs, comparisons, trends, and exceptions.
3. Load independent data concurrently on the server and isolate slow widgets with Suspense.
4. Provide labels, textual summaries, units, ranges, and empty/error/stale states.
5. Use restrained responsive design and lazy-load heavy visualization code.
6. Validate tenant isolation and query/index cost; test metrics, authorization, layout, and bundle impact.
